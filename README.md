# Simple Reviewer Web App

A simple and responsive study reviewer built with **Next.js, TypeScript, Tailwind CSS, and Supabase**.

Create your own review decks, add questions, and practice using flashcards or multiple-choice quizzes.

## Features

- 🔐 Passcode-protected access
- 📚 Create, edit, and delete review decks
- 📝 Add, edit, and delete questions
- 🃏 Flashcard mode
- ❓ Multiple-choice mode
- 🔀 Randomized questions
- ✅ Automatic scoring
- 🟢 Correct / 🔴 incorrect answer feedback
- 📊 Review results and percentage score
- 📱 Responsive desktop and mobile interface
- ☁️ Supabase database
- 🚀 Vercel deployment

## Tech Stack

- **Next.js**
- **TypeScript**
- **Tailwind CSS**
- **Supabase**
- **Vercel**
